# „Hey Siri, Odi“ – Assistent per Sprache starten

Ein Browser kann nicht dauerhaft auf ein Weckwort lauschen. Siri übernimmt das: ein Kurzbefehl öffnet den Lebenshub direkt im Assistenten (Link-Zusatz `#odi`).

## Kurzbefehl anlegen (iPhone / iPad, einmalig)
1. App **Kurzbefehle** öffnen → **+** (neuer Kurzbefehl).
2. Aktion **„URL öffnen“** hinzufügen und als URL den Link deines Lebenshubs mit `#odi` am Ende eintragen, z. B. `https://claude.ai/artifact/<deine-ID>#odi`.
3. Oben den Namen auf **Odi** ändern → Fertig.
4. Sagen: **„Hey Siri, Odi“**. Der Lebenshub öffnet sich im Assistenten, Odi meldet sich mit „Ja, Sir?“.
5. Auf das Mikrofon der Tastatur tippen und sprechen. Odi antwortet und liest vor (🔊 im Assistenten an).

Tipp: Den Kurzbefehl zusätzlich auf den Home-Bildschirm legen oder der Action-Taste zuweisen.

## Stimme einstellen
- Im Lebenshub unter ⚙︎ → **Assistent „Odi“**: Name, Persönlichkeit (KI-Butler mit trockenem Humor), Stimme, Tempo, Tonhöhe, Anrede „Sir“, **Probe hören**.
- Bessere Stimme laden: iPhone-Einstellungen → Bedienungshilfen → Gesprochene Inhalte → Stimmen → Deutsch → eine **Erweitert/Premium**-Stimme (z. B. „Markus“ oder „Yannick“) laden, danach im Hub auswählen.
- Etwas tiefere Tonhöhe (ca. 0,85) und Tempo 1,0 klingen am souveränsten.
