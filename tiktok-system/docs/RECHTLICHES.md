# Rechtliches und Plattformregeln (Arbeitsstand, keine Rechtsberatung)

- **KI-Kennzeichnung:** Das System setzt `aiDisclosure` verpflichtend, blendet „Stimme: KI“ im Video ein und ergänzt „Stimme KI-generiert.“ in der Beschreibung. Zusätzlich beim Upload den KI-Hinweis der Plattform setzen, soweit Buffer das unterstützt – sonst in der TikTok-App nachtragen.
- **Belege:** Jede Zahl braucht eine Quelle; vor Veröffentlichung öffnet ein Mensch jede Quelle und setzt `verified: true` (QA blockiert sonst in Modus B/C).
- **Nutzungsrechte:** Standardmäßig nur im Code gezeichnete Grafiken und Systemschrift (DejaVu, freie Lizenz). Fremde Bilder/Musik nur mit Lizenz aus `qa.allowedLicenses`; Lizenz und Herkunft je Asset im Paket angeben.
- **Stimme:** Nur ElevenLabs-Stimmen nutzen, deren Nutzungsbedingungen kommerzielle Verwendung erlauben; keine Stimmen realer Personen nachbilden.
- **Remotion-Lizenz:** kostenlos für Einzelpersonen und kleine Unternehmen; größere Firmen brauchen eine Firmenlizenz (Bedingungen auf remotion.dev prüfen).
- **Impressum/Werbung:** Bei geschäftlicher Nutzung Kennzeichnung von Werbung und Kanal-Impressum beachten.
